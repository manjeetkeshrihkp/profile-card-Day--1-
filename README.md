# Profile Card UI – Responsive HTML & CSS Profile Card Design

A clean, modern **profile card UI component** built with pure **HTML5 and CSS3** — no frameworks, no JavaScript required. This responsive profile card design is perfect for portfolios, personal websites, developer showcases, and front-end learning projects.

## 🔍 About This Project

This **CSS profile card** is a lightweight, beginner-friendly front-end UI component that demonstrates key CSS concepts like Flexbox layout, absolute positioning, hover effects, and box-shadow styling. It's ideal for developers looking to learn how to build **profile cards with HTML and CSS**, or for anyone searching for a **free profile card template** to customize for their own portfolio or personal brand website.

## ✨ Features

- 🖼️ Circular profile picture with clean border styling
- ☰ Menu and ⚙️ settings icon overlays
- 📱 Social media icon row (Instagram, Telegram, Dribbble)
- 🔘 Rounded "Follow" call-to-action button with shadow effect
- 📄 Expandable bottom panel for additional profile details
- 📐 Fully responsive layout using CSS Flexbox
- 🎨 Custom background image support

## 🛠️ Built With

- **HTML5** – semantic markup structure
- **CSS3** – Flexbox, positioning, box-shadow, border-radius, hover states
- **Google Fonts** – Poppins typeface

## 🚀 Getting Started

### Prerequisites
No dependencies or build tools needed — just a web browser.

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/profile-card-ui.git
   ```
2. Navigate to the project folder:
   ```bash
   cd profile-card-ui
   ```
3. Open `index.html` in your browser.

That's it — no npm install, no build step required.
